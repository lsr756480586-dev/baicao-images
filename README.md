# 百草园人物图片

用于《百草园·云梁纪事》的正常人物立绘与情节插图。仓库布局与原卡五个内部图片分类逐项对应。

## 放图方式

每个人物有自己的文件夹。立绘放为“人物名/立绘.png”；情节图放为“人物名/原卡内部分类/编号.png”。编号从1开始，必须对应同一个人物、同一个分类的数组位置。

例如怀庆日常第1图放为“怀庆/sfw/1.png”。其他分类的文件夹名保留原卡代号；放入的是正常故事图片。

- **日常**：内部目录 `sfw`。人物实际在场，进行园务汇报、种粮育药、修器织染、用餐饮茶或公开会面，且画面适合当前情节。
- **诊疗照护**：内部目录 `肛交`。人物实际在场，在药房、诊室或休养房间接受诊察、包扎、调息指导，或照料另一名同处室内的成员；使用正常衣着和非露骨画面。
- **出行护送**：内部目录 `足交`。人物实际随队采购、护送流民、巡守或赶路，并出现与图片对应的出发、行进、避雨、歇脚或归来情境。
- **私室交谈**：内部目录 `口交`。人物与园主或其他成员确实共同处于书房、茶间、休息室或客房，进行商议、倾诉旧事、解释顾虑或表达关心；亲近按既定人物关系发展。
- **协作修习**：内部目录 `性交`。人物实际在场，共同研习术法、调试符器、练剑、试制农具兵器或协作完成一项工作，出现与图片对应的操作、指点或成果展示。

可以分批补图，不必一次填满。文件夹里的“放图说明.txt”只用于网页上传时保留目录，不是图片。若使用JPG或WebP，请保留真实扩展名，接入角色卡时同步修改地址。

## 具体图片与触发条件

“图片位置清单.csv”逐项列出原链接、新链接模板、分类触发条件和待填写的具体图片画面。上传正常图片后，填写该张图实际表现的场景，才可据此选择编号。分类触发条件只是允许范围，不代表原图已符合这个画面。

ready=false 表示该类正常图片尚未接入，故事提示规则暂不自动输出该分类；解析器仍支持全部原标签。更换新图时同步填写具体图片情境，并更新对应人物和分类的启用范围；未替换的槽位继续保留原链接，仅供后续迁移。

图片不是固定章节；仅在人物确实在场、情节已经发生且图与场景相符时显示。不得因为需要配图强行推进事件。

## 上传GitHub

图片仓库已创建：https://github.com/lsr756480586-dev/baicao-images，默认分支main。使用Add file → Upload files，将本目录的内容上传到仓库根目录，不要额外套一层baicao-images目录。正常图片上传完成后，再按清单统一更新整张卡里的图片地址。

CSV中的新链接模板已使用本仓库用户名。图片尚未上传的地址暂不可用。中文文件夹会编码成百分号形式，这是正常的网址编码。

## 角色卡接入

立绘需同步更新开场菜单、状态栏默认立绘、图库默认立绘与图库数据。情节图片更新对应人物的behaviors[内部分类][编号-1]。原标签格式和编号循环容错保持不变。新图片上线后应检查直链确实返回图片，再更新世界书触发说明和已接入编号；没有新图的槽位暂留原链接。

## 每个编号的正常画面规划

CSV已为每个编号填写计划图片画面及建议播放条件，可以据此准备正常新图。计划不是当前原链接的内容说明，也不代表场景已经在故事里发生。图片上传后仍需核对实际画面；若画面与计划不同，修改说明和触发条件后再接入，不强行匹配。原日常图暂沿用旧规则，其他类别待正常图片接入；准备模板本身不会更新角色卡链接或启用尚未提供的图片。
